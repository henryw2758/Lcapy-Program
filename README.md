# Netlist to Text

Generate human-readable descriptions from SPICE-like circuit netlists for accessibility purposes.

This is a Python port of the [NetlistToText](https://github.com/johnjhealy/NetlistToText) Java application, designed to work seamlessly with the [Lcapy](https://github.com/mph-/lcapy) circuit analysis library.

## Features

- **SPICE Netlist Parsing**: Read standard SPICE-like netlist files (.net, .cir, .spice)
- **Analog Component Support**: Supports resistors, capacitors, inductors, voltage/current sources, and conductances
- **Connection Analysis**: Automatically detects and describes parallel and series connections
- **Lcapy Integration**: Can parse Lcapy Circuit objects directly or read files generated by Lcapy
- **Node Conversion**: Converts SPICE node notation (N001, 0) to readable text ("node 1", "ground")
- **Waveform Support**: Handles PULSE, EXP, SINE waveforms and other value specifications
- **CLI Interface**: Simple command-line tool for automation and scripting

### Basic Installation


## Usage

### Basic Usage (SPICE Netlist)

```bash
# Read a SPICE netlist file
netlist-to-text circuit.net

# Save description to file
netlist-to-text circuit.net -o description.txt

# Verbose mode with parsing details
netlist-to-text circuit.net -v
```

### Lcapy Integration

```bash
# Auto-detects Lcapy Python scripts
netlist-to-text my_circuit.py

# Force Lcapy format
netlist-to-text my_circuit.py -f lcapy
```

### Python API

```python
from netlist_to_text import Circuit

# From file
circuit = Circuit()
circuit.from_netlist_file("circuit.net")
description = circuit.generate_description()
print(description)

# From Lcapy (requires lcapy installed)
from lcapy import Circuit as LcapyCircuit

lcapy_cct = LcapyCircuit('R1 1 2 1k; R2 2 0 2k')
circuit = Circuit()
circuit.from_lcapy(lcapy_cct)
description = circuit.generate_description()
print(description)
```

## Input Format

### SPICE Netlist Format

Supported components:
- `R` - Resistor (Ohm)
- `L` - Inductor (Henry)
- `C` - Capacitor (Farad)
- `V` - Voltage source (Volt)
- `I` - Current source (Amp)
- `G` - Conductance (Siemen)

Example netlist:
```
* Voltage divider circuit
V1 0 1 10
R1 1 2 1k
R2 2 0 2k
```

### Lcapy Format

Standard Lcapy Circuit definitions are supported:

```python
from lcapy import Circuit

cct = Circuit('R1 1 2 1k; R2 2 0 2k')
```

## Output Format

The tool generates human-readable descriptions suitable for screen readers and accessibility tools.

Example output:
```
There are 3 elements and 2 nodes in this circuit.

Between ground and node 1, a 10 Volt voltage source labelled V1 is connected. 
The positive terminal of the voltage source is connected to ground and negative terminal is connected to node 1.

Between node 1 and node 2, a 1k Ohm resistor labelled R1 is connected.

Between node 2 and ground, a 2k Ohm resistor labelled R2 is connected.

Between node 1 and node 2, a 1k Ohm resistor labelled R1 is connected in series with a 2k Ohm resistor labelled R2, these elements are connected at node 2.
```

## Connection Analysis

The tool automatically analyzes circuit topology:

### Parallel Connections
Elements connected between the same two nodes are described as parallel:
```
Between ground and node 1, a 1k Ohm resistor labelled R1 is connected in parallel with a 2k Ohm resistor labelled R2.
```

### Series Connections
Elements sharing a node with exactly two connections are described as series:
```
Between ground and node 1, a 1k Ohm resistor labelled R1 is connected in series with a 2k Ohm resistor labelled R2, these elements are connected at node 1.
```

## Limitations

- **Analog-only**: Supports 2-terminal analog components only (R, L, C, V, I, G)
- **No multi-terminal**: Does not support transistors (Q, M), op-amps (XU), switches, etc.
- **SPICE subset**: Supports a subset of SPICE syntax focused on analog components
- **No analysis**: Generates descriptions only, does not perform circuit analysis
